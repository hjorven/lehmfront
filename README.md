# Lehmfront

Taktisches Grabenkriegsspiel in 2D für den Browser. Rundenbasiert mit gleichzeitiger Befehlsausführung, in einer fiktiven Welt.

Spielen: https://hjorven.github.io/lehmfront/

- Spielplan: `docs/plan.md`
- Arbeitspakete: `docs/arbeitspakete.md`
- Stand: `docs/status.md`
- UI-Mockup: `docs/mockup/lehmfront-ui.html`

## Lokal

```bash
npm test
npm run serve
```

Danach http://localhost:8080/ öffnen. Kein Build-Schritt, reine ES-Module.
